# Form Filler

A form filler that fills all form inputs (dropdowns, textboxes, textareas, radio buttons, etc.)

The purpose of this extension is to ease peoples life in applying for hundred of identical Online Job Application Forms
as this extensions avoids the need for manually entering values in fields.

- Fills all text boxes in a form.
- Supports the maxlength property.
- Selects radio buttons, dropdown menus and checkboxes.
- Ignores CAPTCHA, hidden, disabled and readonly fields


Open Source and without any bloatware
